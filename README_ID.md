# Ranking Position Ladies — Festival Citylink (perbaikan)

Paket ini memakai template PowerPoint FESTIVAL CITYLINK yang Anda kirim, disimpan ulang untuk menormalkan file. Template telah diuji dapat dibaca oleh python-pptx dan memiliki 26 slide.

## Jalankan
1. Ekstrak ZIP ke folder baru.
2. Buka CMD di dalam folder `ranking_position_app`.
3. Jalankan `python -m pip install -r requirements.txt`.
4. Jalankan `python -m streamlit run app.py`.
5. Buka `http://localhost:8501`.

Tanggal mulai dan akhir dapat dipilih di aplikasi. Nilai awal 19–25 OCT 2026. Foto display asli yang dimasukkan ke slide; PICT hanya referensi pilihan.
